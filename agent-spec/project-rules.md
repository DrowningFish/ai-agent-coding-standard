- 每项可标为“已确认/工程已核实/待确认/不适用”，附必要来源。代码可证明技术事实，不能证明部署、提交、数据修改等操作授权。
- 用户明确同意沿用默认时再记录“沿用默认”；未填写不等于已同意，也不阻止无关工作。新决定覆盖旧决定时更新当前内容并保留来源。
- 只在当前任务依赖的信息缺失时询问，不追问全部空项；不把讨论建议写成生效要求，不记录凭据。
