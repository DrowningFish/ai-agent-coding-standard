# 约束规范索引

与根[AGENTS.md](../AGENTS.md)一起复制使用。先按任务需要阅读，不默认全部加载；模板仓库本身不执行业务工程的文档流程。

| 文件 | 职责 |
| --- | --- |
| [project-rules.md](project-rules.md) | 用户或Agent逐步填写的项目约束、来源和状态 |
| [workflow.md](workflow.md) | 分流、需求归属、接入、实施、验证、恢复及交接 |
| [security.md](security.md) | 敏感数据、Git、评审、工具权限及协作 |
| [document-format.md](document-format.md) | 实际需要记录的业务文档 |
| [delivery.md](delivery.md) | 已明确要求的产物及校验 |
| [backend-java.md](standards/backend-java.md) | Java/Spring编码、中文注释、日志、数据库与性能 |
| [frontend.md](standards/frontend.md) | Vue/React实现、异步状态及交互验证 |
| [api.md](standards/api.md) | 接口契约、参数、权限及错误处理 |

已有稳定技术栈、目录、契约和工具优先，专项规范只用于对应技术栈；项目明确选择可调整默认值。禁止把假设、空白或其他项目的历史规则当作当前事实。
